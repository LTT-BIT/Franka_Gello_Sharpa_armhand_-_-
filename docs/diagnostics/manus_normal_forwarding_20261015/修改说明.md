# 普通 MANUS 统一入口与独立入口对齐

适用：`./ops/run/run_gello_full_teleop.sh --hand-source manus --hardware` 的普通 MANUS 路径及其 fake 测试路径。

| 检查项 | 独立入口默认行为 | 统一入口修改前 | 统一入口修改后 |
|---|---|---|---|
| 新命令中断后自动停手 | 原始 watchdog=0 | 200 ms | watchdog=0；短暂缺帧不锁停、不撤销跟随许可；合法新目标恢复后继续 |
| V4 求解后输出时效 | 关闭 | 150 ms | 关闭该额外输出检查；原来的 250 ms 输入检查保留 |
| raw/最终命令两级过期检查 | 无 full 检查 | 两处 200 ms | 普通跟随不走两级检查 |
| 相邻目标突跳 | 无 full 跳变门禁 | 中等告警、极端锁停 | 不叠加跳变门禁；保留原关节限位与有限值校验 |
| 原始关键点与目标匹配 | 无精确 stamp 匹配 | 必须匹配 | 不再等待匹配，直接处理映射目标 |
| 接收历史队列 | 普通驱动订阅 | target depth=1000 | target depth=1，取最新目标；测试验证 DDS burst 不回放历史目标 |
| GUI 心跳/启用许可 | 无 full GUI 许可 | 50 ms 心跳＋200 ms 活跃许可 | 保留 Start/Stop 与认证连接；普通跟随不因心跳慢回复或超 200 ms 自动锁停；真实连接断开撤销许可，重新连接需手动 Start |
| 待机获取 | 无 full 获取门禁 | 30 帧＋30 秒获取超时 | 不叠加帧数/30 秒获取门禁，待机不锁死 |
| 故障恢复 | 合法新指令继续 | 多种源数据异常锁双手 FAULT | 无效单帧丢弃，合法新帧继续；真实设备断开、SDK 发送失败或驱动归属冲突仍停止 |
| Open hand | 非同一 GUI 动作 | 退出跟随并逐步回零 | 保留；所选手退出跟随，回到 22 维零位，完成后不自动恢复 |

Open hand 是显式动作，仍保留它自身的 GUI 活跃连接、固定目标授权、反馈检查、执行与收敛超时。它不依赖手套连续输出，普通跟随策略与这项动作分开。

## 实现

- `adapters/manus/normal_hand_runtime.py`：普通 MANUS 的转发许可与显式 Open hand 路径；不使用验收状态机。闲置反馈使用订阅缓存，普通目标发送前不再同步重复读取反馈。
- `adapters/manus/teleop.launch.py`：项目内拥有的 launch 副本，普通 MANUS 选择 watchdog=0、max_output_age=0、无可靠关键点匹配要求。避免直接修改未跟踪的 portable 依赖。
- `ops/run/run_sharpa_hands_cyclonedds.sh`：仅带 full-config 的 MANUS 入口选择项目 launch；独立入口与 LitchiBot 的执行路径保持原样。
- `adapters/litchibot/validation_driver.py`：为普通 MANUS 选择新的 authority/runtime；显式 Stop/Open 所需的原始 SDK 停用与重新启用路径保留，监督验证仍走原严格路径。

未修改供应商 SDK、标定、采集配置、数据格式、实体限位或速度/电流系数。既有未提交的 Open hand 与 GUI 改动已保留。

## 验证

- 新的 MANUS 假设备集成验证覆盖：长期待机、合法大幅跳变、NaN/Inf/越界/错序拒绝、缺帧后恢复、慢心跳、真实 GUI 断开后不能自动恢复、SDK 发送失败停手、真实 DDS 深度 1 接收突发流。
- 既有 Open hand 集成测试覆盖：单手、双手、另一手仍在跟随；通过原始 mock SDK sender 实际到零，完成后跟随许可保持关闭。
- 新入口真实命令行 fake smoke 运行 12 秒：MANUS fake、Sharpa fake，日志确认 watchdog=0.00、normal_session=True、新运行时被加载。结束时 SIGINT 的退出 traceback 属于预定关闭。
