## 两种手套的单入口启动

先正常退出旧 arms/hands 终端及其他 full 会话。新旧入口互斥运行。

MANUS → Sharpa，加双臂和 GUI：

```bash
cd /home/descfly/ZH/gello_upper_body_teleop
./ops/run/run_gello_full_teleop.sh --hand-source manus --hardware
```

LitchiBot → Sharpa，加双臂和 GUI：

```bash
cd /home/descfly/ZH/gello_upper_body_teleop
./ops/run/run_gello_full_teleop.sh --hand-source litchibot --profile LYG226360006 --hardware
```

这些命令连接实体设备。启动后运动授权默认关闭，在 GUI 分别使用左右 `Start arm`、`Start hand`；对应 `Stop hand` 撤销跟随，`DISENGAGE ALL` 撤销臂和手授权。新手套 Stop 保持 SDK 会话及设备连接，不等同于硬件断电/disable。当前 full 模式 `Open hand` 尚未提供经过验证的姿态，点击会拒绝发送。

退出时先结束当前录制，再点击 `DISENGAGE ALL`，在遥操终端按 Ctrl+C 并等待清理完成。录制器由自己的终端退出。

将 `--hardware` 换为 `--dry-run` 时，Sharpa 使用假设备，手套仍为真实输入；**双臂仍执行原生产启动流程，不能将 full dry-run 当作整个系统的仿真入口。** 新手套无臂的数据检查应使用上一节独立 dry-run 脚本。
